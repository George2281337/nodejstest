# nodejstest

Мини-приложение на Node.js: таблица товаров с добавлением, редактированием и удалением, данные хранятся в SQLite.

Без внешних зависимостей — используются встроенные модули `node:http` и `node:sqlite` (нужен Node.js 24+).

## Запуск

```bash
npm start
```

Откройте http://127.0.0.1:3000

## Настройки (переменные окружения)

| Переменная | По умолчанию  | Назначение            |
|------------|---------------|-----------------------|
| `PORT`     | `3000`        | Порт сервера          |
| `HOST`     | `127.0.0.1`   | Адрес прослушивания   |
| `DB_PATH`  | `data/app.db` | Путь к файлу базы     |

## API

| Метод    | Путь                | Описание          |
|----------|---------------------|-------------------|
| `GET`    | `/api/products`     | Список товаров    |
| `GET`    | `/api/products/:id` | Один товар        |
| `POST`   | `/api/products`     | Создать товар     |
| `PUT`    | `/api/products/:id` | Изменить товар    |
| `DELETE` | `/api/products/:id` | Удалить товар     |

Тело запроса: `{ "name": "...", "category": "...", "price": 9.99, "quantity": 3 }`.

## Тесты

```bash
npm test
```

## Структура

- `server.js` — HTTP-сервер, маршруты, валидация
- `db.js` — схема и запросы к SQLite
- `public/` — страница с таблицей
- `test/` — тесты API
